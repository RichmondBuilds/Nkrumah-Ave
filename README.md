## 🚀 Featured Project

### 🟢 [Nkrumah Ave](https://nkrumahave.shop) — Live Streetwear E-Commerce Platform

> *Built from scratch. No frameworks. No templates. Just code.*

A fully functional e-commerce store for Ghana-rooted streetwear — hand-coded in **Vanilla JavaScript** with a **Firebase** backend.

**What it does:**

- 🛒 Real-time product catalog synced from Firestore
- 💳 Paystack payment integration (card + Mobile Money)
- 💬 WhatsApp checkout flow
- 📦 Admin dashboard — add, edit, delete products, manage stock
- 🔐 Secure admin authentication via Firestore (password never in code)
- 🖼️ Cloudinary media uploads (photos + videos per product)
- ⏱️ Discount timer — flash sales that auto-expire
- 🔔 Pre-order system for sold out items
- 🚚 Delivery fee calculator across all 16 Ghana regions
- ❤️ Wishlist, coupon codes, order history, referral system
- 📱 Fully mobile-optimised — built and tested on a phone

**Stack:**
`Vanilla JavaScript` · `Firebase Firestore` · `Firebase Auth` · `Cloudinary` · `Paystack` · `GitHub Pages`

**Live:** [nkrumahave.shop](https://nkrumahave.shop)
